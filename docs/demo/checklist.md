# 演示前检查

照着从上到下过一遍，大约 5 分钟。命令都在仓库根目录运行，详细说明见 [Demo 指南](README.md)。

## 1. 代码和数据（演示前 30 分钟以内）

- [ ] 使用 `main` 上的当前演示版本，虚拟环境 `.venv` 已建好、依赖已装。
- [ ] 准备一个**全新**的演示目录（不要用上次演示过的目录）：

```bash
.venv/bin/python scripts/demo/prepare_demo.py
```

- [ ] 记下它打印的目录，用它启动。端口被占用就在末尾换一个端口：

```bash
scripts/demo/run_demo.sh ~/roleradar-demo/demo-日期-时间
```

- [ ] 终端里看到“Uvicorn running on http://127.0.0.1:8850”。
- [ ] 浏览器打开 <http://127.0.0.1:8850>，点“以合成用户 A进入”，进入“工作台”。
- [ ] 工作台“最近保存”里有预先保存的记录：岗位分析、我的岗位、查找摘要、方向探索，以及经历（只列最近的几条）。
- [ ] 快速确认三处：
  - 经历库里两段经历都是“已确认”；
  - 求职偏好里有“最早 2027 年 1 月入职”；
  - “我的岗位”里有“数据分析实习生（合成示例 JD）”，并带着预先保存的备注。

## 2. 结果有效期

- [ ] 不要提前跑好结果、开着页面等：探索、查找、分析的结果页只保留 30 分钟，服务重启后就没有了。现场重跑只要几秒。
- [ ] 如果在第 1 步之后重启过服务，临时结果已清除；保存过的记录还在。
- [ ] 用到预先保存的记录时，口头说明“这是演示前预先保存的结果”。

## 3. 窗口、缩放和语言

- [ ] 用一个干净的浏览器窗口（访客窗口或单独的浏览器配置）：
  - 没有个人标签页、书签栏、扩展图标或已登录账户；
  - 只开 RoleRadar 一个标签页。
- [ ] 窗口宽度在 1280–1440 左右，缩放 100%。投屏时可以放大到 110%，先确认两栏布局没有挤乱。
- [ ] 界面语言选“简体中文”（用户菜单里切换）。对英文观众可以切到 English，但要先说明合成资料是中文写的。
- [ ] 终端窗口最小化或移到另一个屏幕：终端里显示的本机路径里有用户名。

## 4. 关闭个人通知

- [ ] 打开“勿扰模式 / 专注模式”，关掉聊天、邮件和日历的弹窗。
- [ ] 隐藏桌面上带个人信息的文件，关掉其他应用里的私人内容。
- [ ] 录屏时只录浏览器窗口或选定区域；不要自动录系统声音，旁白另录或现场讲。

## 5. 备用方案

- [ ] 讲稿 [script.md](script.md) 打开在另一块屏幕或打印出来；备用短路径在第 C 节。
- [ ] 来不及或结果过期：切到预先保存的记录（讲稿 C2），并说明是预先保存的。
- [ ] 服务完全起不来：用 [screenshots/](screenshots/) 里的 6 张真实截图讲。它们是同一套合成资料的截图，不是设计效果图；讲的时候说明是截图。
- [ ] 手动示例 JD 的全文在 [fixtures/supplied_jd.txt](fixtures/supplied_jd.txt)，备用短路径要粘贴它。

## 6. 演示以后

- [ ] 在运行服务的终端按 Ctrl-C 停止；终端回到命令提示符就是停了。
- [ ] 演示目录在仓库外面（默认 `~/roleradar-demo/`），不会被提交；不需要就自己删掉，脚本不会删除任何东西。
- [ ] 下次演示重新准备一个新目录。
